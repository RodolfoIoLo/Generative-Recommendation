# 🔧 生成训练管线验证

本页记录正式三种子训练前的检查，验证分数只用于调参；项目已完成，正式结果见[主实验报告](../06-reports/main_results.md)。

| 检查 | 实际结果 |
|---|---|
| 冻结接口 | 六份文件通过结构、码值、唯一性、可逆性与输入哈希检查 |
| 模型输入 | 981,491个前缀样本；最多20部电影；1,027个Token；11,281,664个随机初始化参数 |
| 端到端运行 | 20步覆盖前向、反向、约束生成、指标计算与best/last写入 |
| 恢复训练 | 从第20步恢复至第30步，包含优化器、学习率与随机状态 |
| 小样本过拟合 | 256个训练样本，loss从第100步3.957463降至第1,000步0.001613 |
| 合法性 | 约束生成无非法ID、已见物品或不足10项列表 |

两档学习率仅在valid上比较，均使用seed42、5,000步和相同1,000名验证用户：

| 学习率 | 最终valid NDCG@10 |
|---|---:|
| 3e-4 | **0.056145** |
| 1e-3 | 0.039042 |

按既定规则选择3e-4。[学习率汇总](../02-learning-rate-selection/pilot_summary.md)保留选择依据；原始审计、运行与过拟合证据分别位于`audit/`、`smoke/`和`overfit/`。小样本过拟合验证训练链路可学习，不代表正式推荐效果。
